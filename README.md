# Idea Trellis

Independent educational website for people starting an online business. Includes software comparisons, original guides, an interactive tool finder, a break-even calculator, and a free 30-day launch checklist.

## Deployment
- Source: this standalone GitHub repository (`main` branch)
- Runtime: static HTML, CSS and JavaScript (no build dependencies)
- Hosting: Render static site; publish path `.`
- Custom domain: `ideatrellis.com` pending purchase and DNS verification.

## Affiliate links
- Systeme.io: user-supplied referral link installed in `affiliate-links.js` and verified to redirect to systeme.io with referral parameters.
- Shopify and Kit: official non-affiliate links until approved personalized referral links are obtained.
- Current commission attribution and payouts can only be confirmed through each partner's dashboard.

## Visitor privacy
The calculator and checklist run in the browser. No email collection, cookie analytics, or account registration is configured on this website.
